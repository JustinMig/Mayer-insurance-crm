# Life Import Manual Name + Agent Requirement

Changes:
- First name starts blank on every document import.
- Last name starts blank on every document import.
- Parsed/OCR name values are not copied into the editable client name fields.
- Assigned agent starts blank.
- User must manually select an agent.
- Save/Create is blocked until first name, last name, and assigned agent are all provided.
- The selected assigned agent is explicitly submitted with the client form.

All other extracted life-insurance, banking, and client data remains available as before.

# Mayer Insurance Group CRM branding update

This build updates the CRM branding to match the supplied Mayer Insurance Group logo artwork.

- Replaces every visible MIG brand mark with the supplied bear artwork.
- Shows the bear in the desktop sidebar, mobile/top header, and login screen.
- Uses the bright blue from the Mayer wordmark for the Mayer Insurance Group brand text.
- Uses the pale blue/gray and warm cream tones from the supplied logo background throughout the app shell and login page.
- Updates the installable/PWA icon to the bear.
- Keeps the existing client section colors and functional layout intact.
- No Supabase/database migration is required for this visual update.

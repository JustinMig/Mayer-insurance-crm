# Mayer Insurance Group CRM — 2026-08-08 Patch

- Added a request-deduplicated CRM session/profile helper using React cache so layouts/pages can share the same auth/profile lookup during one render.
- Added a CRM loading state for faster perceived navigation.
- Replaced the missing-agency dashboard crash with an account-setup redirect/screen.

## Security
- API/application routes remain behind authentication middleware; only static/public assets bypass Proxy.
- No public caching was added to client or sensitive CRM data.

# Dashboard color + Medicare comparison update

Updated dashboard behavior:

- Color-coded dashboard lookup controls so Company Directory, Medicare, Height & Weight, and Medical Qualifications are visually distinct.
- Medicare plan results now load collapsed by default; select the plan header to open/close benefit details.
- Added Compare selection to Medicare plans with a maximum of 4 plans.
- Added side-by-side Medicare comparison for monthly premium, MOOP, PCP, specialist, inpatient hospital, OTC, food/nutrition, dental, vision, and hearing.
- Comparison selections reset when a new county/Medicaid search is run.
- Mobile layout remains responsive; the comparison table scrolls horizontally when needed.
